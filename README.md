# Knowledge Review

面向 Obsidian 桌面端和移动端的知识摘录与间隔复习插件。

## 主要功能

- 任意选择一段文字、多个段落或列表内容，追加到固定的“摘录库”笔记。
- 新摘录使用不可见标记同步原文，不再给原文添加可见的 `^块 ID` 下标。
- AI 从选区中建议关键词；关键词会在原文中显示为高亮链接，点击可跳到摘录卡片。
- 阅读模式下点击整张摘录卡，可跳回原文的准确位置。
- 支持卡片标题、颜色和来源章节显示。
- 手动用多个 `==高亮==` 制作一张多挖空闪卡。
- AI 建议多个挖空，保存前可修改、关闭和确认。
- 从任意选区生成 AI 问答闪卡，保存前可预览、编辑和删除。
- 从相册或文件导入图片，手动拖动画方块挖空，不需要 AI。
- 文字挖空和图片方块可逐个点击显示；显示后在卡片下方选择复习效果。
- 按标签分区展示和管理闪卡，多标签卡在各分区均出现，无标签归入未分类。支持创建时间正序/倒序、最近修改、最近到期排序。
- 卡片用颜色铺底，显示可编辑的关键词和简短预览；图片标题手动输入，留空自动编号。
- 图片遮挡完全不透明；点击选择后拖动中心移动、拖动四角缩放，支持撤销和删除单个方块。
- 大窗口编辑内容、标题、颜色和标签，编辑不会回写原文。
- 点击来源跳到笔记的选区或图片块。新图片保存在当前笔记，没有当前笔记时保存在图片闪卡来源笔记；旧图片卡首次点击来源时补建来源笔记。
- 旧文字卡缺少定位信息时，可在编辑框补填原文定位文本。
- 未来 30 天显示已确定到期量，以及每次选择“记得”时的预计复习总量。
- 月历用颜色深浅显示复习次数，复习越多颜色越深。
- 固定艾宾浩斯间隔和动态间隔两种复习算法。
- 今日复习侧栏、来源/标签/颜色/卡组筛选、复习日历和完成统计。
- 打开 Obsidian 时提醒到期卡片；所有创建命令都可加入移动工具栏。

## 安装

把 `main.js`、`manifest.json`、`styles.css` 放到 GitHub 仓库根目录；将 `.github/workflows/release.yml` 放到对应路径。首次上传工作流时，GitHub 可能要求在网页上创建该路径并粘贴文件内容。此后每次更新，把三个运行文件和版本号增加后的 `manifest.json` **在一次提交中上传到 main 分支**。工作流会建立与 manifest 版本相同的 Release，并将三个运行文件分别作为附件，BRAT 即可检查更新。也可以手动创建同版本 Release 并分别上传附件。

在 BRAT 中把本仓库设为跟踪最新版本（不要使用固定版本），执行「检查测试版插件更新」。更新插件时不要卸载重装。

**不要删除本机仓库的 `.obsidian/plugins/knowledge-review/data.json`。** 闪卡、复习记录和插件设置都在其中。它含 API 密钥，不应上传到公开 GitHub 仓库。GitHub 仓库根目录无需 `data.json`；自动更新仅替换程序文件。

## 配置 AI 接口

### 智谱免费模型（推荐）

1. 在智谱 BigModel 开放平台注册并创建 API Key。
2. 打开「设置 → Knowledge Review → AI 自动出题」。
3. 点击「智谱免费」，插件会自动填写：
   - 兼容接口地址：`https://open.bigmodel.cn/api/paas/v4`
   - 模型名称：`glm-4-flash-250414`
4. 粘贴智谱 API Key，然后点击「测试连接」。

### DeepSeek 低价模型

1. 在 DeepSeek 开放平台创建 API Key 并确保 API 账户有余额。
2. 在插件设置中点击「DeepSeek」，插件会自动填写：
   - 兼容接口地址：`https://api.deepseek.com`
   - 模型名称：`deepseek-flash`
3. 粘贴 DeepSeek API Key，然后点击「测试连接」。

### OpenAI 或其他兼容接口

点击「OpenAI」可恢复 OpenAI 预设；也可以直接修改接口地址和模型名称，连接其他兼容 Chat Completions 的服务。

密钥保存在本地插件数据 `data.json` 中，不要把该文件或密钥提交到 GitHub。

## 导入图片制作方块挖空卡

1. 执行命令「导入图片并画方块挖空闪卡」，选择一张 PNG、JPEG 或 WebP（不超过 10 MB）。
2. 在图片上用手指或鼠标拖动，框住想记忆的答案。可撤销或清空，支持一张图多个方块。
3. 填写标题、卡组和复习算法后保存。图片保存在仓库的 `Knowledge Review/图片挖空/`，方块位置保存在插件闪卡数据中。同步仓库时需同步原图。
4. 今日复习中点击某个方块会露出图片原内容；点击后下方显示「忘记／困难／记得」。

图片挖空不调用 AI。科目一截图的题目及答案由你决定遮挡范围。

## 创建知识摘录

1. 在源笔记中选中任意连续内容，不要求是完整段落。
2. 执行命令「将所选内容摘录到摘录库」。
3. AI 会建议一个原文关键词；可在弹窗中修改关键词、标题和颜色。
4. 确认后，插件自动创建或更新设置中指定的 `摘录库.md`。
5. 原文关键词成为高亮链接：点击它跳到摘录卡；在阅读模式点击摘录卡则跳回原文。

新卡片在摘录库中以可读代码块保存：

````markdown
```knowledge-card
source: 日语/N2阅读.md
marker: krm-example
title: 才能与结果
color: purple
showHeading: true
```
^krcard-example
````

原文只增加阅读模式不可见的同步标记，并将一个关键词变成高亮链接。旧版使用块 ID 创建的摘录仍然兼容。

## 手动创建多挖空闪卡

1. 在原文中给所有要挖空的词加高亮，例如：

   ```markdown
   ==海马体==参与记忆形成，==睡眠==有助于记忆巩固。
   ```

2. 选中包含这些高亮的任意范围。
3. 执行「将选区内的高亮创建为多挖空闪卡」。
4. 设置卡组、标签、颜色和复习算法后保存。

每个高亮会成为独立挖空：`{{c1::海马体}}`、`{{c2::睡眠}}`。
复习时点击每个挖空位直接显示该词；卡片下方出现复习效果选项。

## AI 创建多挖空闪卡

1. 选中任意学习材料。
2. 执行「从所选内容 AI 生成多挖空闪卡」。
3. 在预览页修改 AI 建议的词语，关闭不需要的项。
4. 设置卡组信息并保存为同一张多挖空卡。

## AI 创建问答闪卡

1. 选中任意学习材料。
2. 执行「从所选内容生成 AI 问答闪卡」。
3. 设置卡组、标签、颜色、算法和生成数量。
4. 在预览窗口修改或取消卡片，确认后保存。

## 复习规则

固定计划默认为当天、1、2、4、7、15、30 天，可在设置中修改。

- 忘记：10 分钟后再次出现，并重置固定计划。
- 困难：使用较短间隔，不推进或缓慢推进复习阶段。
- 记得：进入下一固定阶段，或按动态算法扩大间隔。

## iPad 提醒限制

社区插件无法在 Obsidian 被系统完全关闭后继续可靠运行。因此插件会在每次打开 Obsidian 时检查到期卡片，并在复习侧栏持续显示数量；不能保证像原生 iOS 应用一样在后台准时推送。
