# Knowledge Review

一个面向 Obsidian 桌面端和移动端的知识摘录与间隔复习插件。

## 功能

- 从其他 Markdown 文件摘录完整段落，阅读模式显示为彩色卡片。
- 原文修改后，摘录卡片自动读取最新内容。
- 点击整张摘录卡片，跳转到源文件的准确块位置。
- 支持手动按文件标题或块 ID 创建摘录。
- 从选区调用 OpenAI 兼容接口生成问答闪卡。
- AI 结果保存前可逐张预览、修改、取消。
- 选择文字创建挖空闪卡。
- 固定艾宾浩斯间隔和动态间隔两种复习算法。
- 今日复习侧栏、来源/标签/颜色/卡组筛选、本月日历和完成次数。
- 打开 Obsidian 时提醒到期卡片。

## 安装

将以下三个文件复制到仓库中的 `.obsidian/plugins/knowledge-review/`：

- `main.js`
- `manifest.json`
- `styles.css`

然后在 Obsidian 的「设置 → 第三方插件」中关闭安全模式并启用 `Knowledge Review`。

移动端安装时，也可先在电脑端安装，再通过你的同步工具同步整个插件目录。

## 使用：知识摘录

1. 在源笔记中选中一个或多个连续段落。
2. 打开命令面板，执行「将所选段落复制为知识摘录卡片」。
3. 设置标题、颜色和章节显示方式。
4. 切换到目标笔记并粘贴。

插件会在源段落后添加一个 Obsidian 块 ID，例如：

```markdown
这是需要摘录的知识点。
^kc-example
```

目标笔记保存的是可读的代码块：

````markdown
```knowledge-card
source: 日语/N2阅读.md
blocks: kc-example
title: 才能与结果
color: purple
showHeading: true
```
````

手动插入时，可以使用 `heading` 代替 `blocks`：

````markdown
```knowledge-card
source: 日语/N2阅读.md
heading: 才能的判断
title: 才能与结果
color: blue
showHeading: true
```
````

## 使用：挖空闪卡

选中同一段落中的关键词，执行「将所选文字创建为挖空闪卡」。插件会把完整段落作为问题，将选中文字隐藏，并把它作为答案。

## 使用：AI 问答闪卡

1. 在插件设置中填写兼容接口地址、模型 ID 和 API 密钥。
2. 选中用于出题的完整段落。
3. 执行「从所选段落生成 AI 问答闪卡」。
4. 设置卡组、标签、颜色、算法和生成数量。
5. 在预览窗口修改或取消卡片，确认后保存。

兼容接口地址应指向 API 的版本根目录，例如 `https://api.openai.com/v1`。插件会请求其 `/chat/completions` 路径。

> API 密钥保存在本地插件数据 `data.json` 中。Obsidian 暂无供社区插件使用的系统密钥库接口，请只使用可信的同步服务和设备。

## 复习规则

固定计划默认为：当天、1、2、4、7、15、30 天，可在设置中修改。

- 忘记：10 分钟后再次出现，并重置固定计划。
- 困难：使用较短间隔，不推进或缓慢推进复习阶段。
- 记得：进入下一固定阶段，或按动态算法扩大间隔。

## iPad 提醒限制

社区插件无法在 Obsidian 被系统完全关闭后继续可靠运行。因此本插件会在每次打开 Obsidian 时检查到期卡片，并在复习侧栏持续显示数量；它不能保证像原生 iOS 应用一样在后台准时推送。

## 开发

```bash
npm install
npm run build
```

构建产物为根目录下的 `main.js`。
